# DoriQidir acceptance mezonlari

- [x] Foydalanuvchi dori nomi yoki faol modda bo‘yicha qidirishi va hudud filtri bilan natijani toraytirishi.
- [x] Har bir dori uchun dorixona manzili, telefon, ish vaqti, narx va mavjud zaxira ko‘rsatilishi.
- [x] Foydalanuvchi ism, telefon va sonni validatsiya bilan oldindan ajratish so‘rovini yuborishi.
- [x] Rezervatsiyalar JSON bazasida saqlanishi va admin kaliti bilan ko‘rilishi.
- [x] Admin rezervatsiya statusini `new`, `confirmed`, `ready`, `collected` yoki `cancelled`ga o‘zgartirishi.
- [x] README, `.env.example`, arxitektura diagrammasi va testlar mavjud bo‘lishi.
